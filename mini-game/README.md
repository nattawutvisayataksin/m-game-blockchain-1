# Mini-Game: Retro Nitro Racer (Grand Prix 8-Racer Edition)

มินิเกมแข่งรถมุมมอง Bird's-eye view (Top-Down 2D) ที่ได้รับการยกเครื่องสนามแข่งใหม่ทั้งหมด: **ถนนกว้าง 250px**, **ทางตรงยาวระดับตำนาน Mega Nitro Straight 3,200px**, และเพิ่มคู่แข่ง **AI รวมเป็น 8 คันในสนาม**!

---

## 🌟 ฟีเจอร์ที่อัปเกรดใหม่ (Grand Prix Upgrades)

### 1. 🛣️ ถนนกว้างพิเศษ 250px (Ultra-Wide Track)
- ขยายความกว้างของถนนจาก 150px เป็น **250px**
- กว้างพอสำหรับให้รถวิ่งคู่คี่เบียดแซงกันได้พร้อมกัน 5-6 คัน
- มีเส้นแบ่งเลน Dual Lane Markers และเส้นประสีทองกลางถนน
- ขอบทางกันกระแทก (Bumper Guardrail) อัปเดตรองรับขนาดถนนใหม่ ชนแล้วเด้งนำร่องไปข้างหน้า ไม่หลุดสนาม

### 2. 🏁 Mega Nitro Straight (ทางตรงยาว 3,200px)
- มีช่วงทางตรงยาวเหยียดสะใจตั้งแต่ **Sector 1 ไปจนถึงทางโค้งขวาสุด** (ความยาวกว่า 3,200 พิกเซล)
- ออกแบบมาให้ผู้เล่นและ AI ได้เหยียบมิดคันเร่ง, กดบูสต์ไนโตรต่อเนื่อง, และเหยียบแผ่น Super Turbo Pads เพื่อทำความเร็วสูงสุดระดับ Supersonic!
- ระยะทางรอบสนามทั้งหมดเพิ่มขึ้นเกือบ **3.5 เท่า (~13,000 พิกเซลต่อรอบ)** ทำให้ 1 รอบรู้สึกเต็มอิ่ม สนุก และมีทั้งโซนทางตรงสปีดสูงและโซนโค้ง S สลับดริฟต์

### 3. 🏎️ แข่งขันพร้อมกัน 8 คันในสนาม (8 Racers Starting Grid)
จัดวางแถวออกสตาร์ทแบบ 2 แถวขนานสลับฟันปลาบนถนนกว้าง:
1. **Player (ผู้เล่น)** - สีนีออนไซยาน Cyan `#00f0ff`
2. **Crimson Comet** - สีแดงสปอร์ต Red `#ef4444`
3. **Gold Rush** - สีทองอำพัน Amber `#f59e0b`
4. **Shadow Drift** - สีม่วงเข้ม Purple `#a855f7`
5. **Emerald Blade** - สีเขียวนีออน Green `#10b981`
6. **Cyber Phantom** - สีชมพูฮอตพิงค์ Pink `#ec4899`
7. **Thunder Bolt** - สีเหลืองอิเล็กทริก Yellow `#facc15`
8. **Cobalt Striker** - สีน้ำเงินรอยัลบลู Blue `#3b82f6`
*(AI แต่ละคันมีระบบ Dynamic Lane Offset วิ่งกระจายเลน แซง และดริฟต์ตามไลน์)*

### 4. 🗺️ Radar Mini-Map ขนาดใหม่
- ปรับสเกลเรดาร์มินิแมพขวาล่างให้ครอบคลุมพื้นที่สนามแข่งขนาดใหญ่ 5,000 x 3,500 พิกเซล
- แสดงจุดไฟบอกตำแหน่งรถแข่งทั้ง 8 คัน และตำแหน่งของแผ่น Boost Pad ทั่วสนามแบบเรียลไทม์

---

## 🏎️ วิธีการเปิดเล่น (How to Play)

- เข้าไปที่โฟลเดอร์ **`mini-game/`**
- ดับเบิลคลิกเปิดไฟล์ **`index.html`** ด้วย Web Browser (Chrome, Edge ฯลฯ) หรือรีเฟรชหน้าต่างเดิมหากเปิดอยู่แล้ว

---

## 🎮 การควบคุม (Controls)

| ปุ่ม | คำสั่ง |
| :--- | :--- |
| **W / ลูกศรขึ้น (↑)** | เหยียบคันเร่ง (Throttle) |
| **S / ลูกศรลง (↓)** | ถอยหลัง / เบรก (Reverse / Brake) |
| **A / ลูกศรซ้าย (←)** | เลี้ยวซ้าย |
| **D / ลูกศรขวา (→)** | เลี้ยวขวา |
| **Spacebar** | กดขณะเข้าโค้งเพื่อ **ดริฟต์สไลด์ (Drift)** / กดทางตรงเพื่อ **Nitro Boost** |
| **R** | รีเซ็ตตำแหน่งรถกลับสู่กลางถนน |
